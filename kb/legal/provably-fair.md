#### What is provable fairness?

Provable fairness is a concept in online gaming that ensures that the outcome of a game is determined by a random process, and that the process cannot be manipulated by the operator or any other party. In other words, it is a way to ensure that the odds of winning are the same for all players, and that the outcome of the game is completely random and unpredictable.

#### How can we make games provably fair?

To make games provably fair, Shuffle.us uses a combination of the following components:

  * server-side seed - a randomly generated value that is created by the operator and used as an input for the random number generator

  * client-side seed - a value that is generated by the player's browser and also used as an input for the random number generator

  * cryptographic nonce - a value that is used to ensure that the outcome of the game cannot be predicted or manipulated

When the game is played, the three components are combined and used as inputs for the random number generator. The output of the generator is then used to determine the outcome of the game. By using a combination of these three values, it becomes virtually impossible for any party to predict or manipulate the outcome of the game.

#### How can gameplay be verified as fair?

To verify that a round is fair, players can check the server-side seed, client-side seed, and cryptographic nonce via the verify page [here](https://shuffle.us/provably-fair/verify).
